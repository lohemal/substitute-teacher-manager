# 보결 배정 시스템

**초등학교** 보결(결보강) 배정을 돕는 Windows 프로그램입니다.
결근한 선생님의 시간을 대신 맡을 수 있는 선생님을 **실제 시각 기준**으로 찾아
학교가 정한 순서대로 추천합니다.

> 자료는 **이 컴퓨터 안에만** 저장됩니다. 외부 서버나 클라우드로 보내지 않습니다.

---

## 무엇을 해 주나요

- **보결 조회** — 날짜·학급·교시를 고르면 그 시간에 정말 비어 있는 선생님을 찾아 줍니다.
  교시 번호가 아니라 실제 시작·종료 시각으로 판단하므로 학년마다 시간이 달라도 정확합니다.
- **추천 순서** — 동학년 우선, 보결 적은 순 등 학교가 기준을 정하고 순서를 바꿀 수 있습니다.
  프로그램은 추천만 하고, 최종 배정은 담당자가 합니다.
- **다건 배정** — 담임이 하루 비울 때 그 날 시간을 한 번에 배정합니다.
- **배정 내역** — 취소해도 기록은 남고, 취소분은 횟수 집계에서 빠집니다.
- **보결 현황** — 오늘·주·달·학기별 현황과 교사별 횟수, 미배정이 남은 날을 보여 줍니다.
- **보결 수당** — 달별로 교사별 지급액을 계산합니다. 1회 금액과 지급 기준(전체 지급 /
  본인 발생분 차감)은 학교가 정합니다. 금액을 따로 저장하지 않고 배정 기록에서 그때그때
  계산하므로, 취소한 배정이나 바뀐 금액이 곧바로 반영됩니다.
- **전담교사 식사시간** — 전담 선생님이 그 날 어느 학년 수업에 들어갔는지 보고 식사시간을
  자동으로 정합니다. 그 시간에는 일반 보결을 맡기지 않지만, 점심 보결은 그대로 맡습니다.
- **점심 보결의 담임** — 학년마다 점심시간이 다른 학교에서, 아직 먹지 않았거나 이미 먹은
  담임에게 점심 보결을 맡길 수 있습니다. 설정에서 켜면 되고, 켜도 자기 학년 점심시간과
  겹치는 선생님은 후보가 되지 않습니다.
- **엑셀 내보내기** — 배정 내역 · 보결 현황 · 보결 수당을 화면에 걸린 조건 그대로
  `.xlsx` 파일로 저장합니다. 숫자는 숫자로 담기므로 바로 합계를 낼 수 있고,
  첫 행 고정과 자동필터가 걸려 있습니다.
- **백업 · 복원** — 자료를 파일 하나로 저장하고 그 시점으로 되돌립니다.

## 설치

[릴리스 페이지](../../releases/latest)에서 `bogyeol_0.1.8_x64-setup.exe` 처럼 생긴 설치 파일을 내려받아 실행하세요.
관리자 권한이 필요 없습니다.

> Windows가 "PC를 보호했습니다" 창을 띄우면 **추가 정보 → 실행** 을 누르세요.
> 코드 서명 인증서가 없는 프로그램은 모두 이렇게 나옵니다.

설치한 뒤에는 프로그램 안에서 **설정 → 프로그램 업데이트** 로 새 버전을 받을 수 있습니다.

## 만드는 방법 (개발)

### 필요한 것

- [Node.js](https://nodejs.org) 20 이상
- [Rust](https://rustup.rs)
- Visual Studio Build Tools (C++ 데스크톱 개발)

### 실행

```bash
npm install
npm run tauri dev
```

### 실제 자료를 건드리지 않고 연습하기

초기 설정을 처음부터 다시 해 보는 것처럼, **자료를 지우는 시험**을 해야 할 때가
있습니다. 그럴 때는 연습용으로 띄우세요.

```bash
npm run app:sandbox
```

자료를 `%APPDATA%\kr.school.bogyeol.sandbox\` 에 따로 만들므로
실제 자료(`kr.school.bogyeol`)는 손대지 않습니다. 창 제목에 **연습용**이라고
나옵니다. 다 끝냈으면 그 폴더를 지우면 됩니다.

### 검사

```bash
npm run build           # 타입 검사 + 화면 빌드
npm run check:model     # 계산 로직 검사 (시정표·명단·정렬 등)
cd src-tauri && cargo test --lib   # 서버 테스트
```

실제 쓰고 있는 자료로 확인하려면 (자료를 복사해서 쓰므로 원본은 안전합니다):

```bash
cd src-tauri && cargo test --lib real_db -- --ignored --nocapture
```

### 설치 파일 만들기

```bash
npm run tauri build
```

배포 절차는 [`docs/02-배포.md`](docs/02-배포.md) 를 보세요.

## 구조

```
src/          화면 (React + TypeScript)
  ipc/        Tauri 명령 호출
  features/   화면별 기능
src-tauri/
  src/domain/ 판단 로직 — DB와 Tauri를 모르는 순수 계산
  src/repo/   SQL 전담
  src/commands/ IPC 진입점
  migrations/ 자료 구조 (여기가 원본)
docs/         설계안 · 배포 안내
```

핵심 규칙 두 가지:

1. **시간은 자정 기준 분(minute) 정수 하나로 다룬다.** 겹침 판단은
   `domain/time.rs` 의 함수 하나만 쓴다 — `a.start < b.end && b.start < a.end`.
2. **`domain/` 은 DB를 모른다.** `repo/` 가 하루치 자료를 읽어 넘겨 주고
   `domain/` 은 그것만 보고 판단한다. 그래서 DB 없이 시험할 수 있다.

자세한 설계 의도는 [`docs/01-설계안.md`](docs/01-설계안.md) 에 있습니다.
